# NAVSTAR analysis and visualization layers

Implemented service primitives:
relationship graph; magnetic connectivity; data lineage; uncertainty heatmap; forecast ghosts; synchronized replay support; correlation explorer; sensor coverage shells; confidence-weighted sensor fusion; spacecraft environmental bubble; conjunction/proximity analysis; route-risk corridor; communications mesh; network-resilience simulation; digital-twin difference mode; model comparison; anomaly constellations; interrogable object explanations; scientific bookmarks; mission playback records; global catalog search.

## Visualization contract
Every rendered node, strand, shell, corridor, ghost, or event should expose object ID, relationship/direction, timestamp, source, uncertainty/confidence, and provenance. Provenance is one of MEASURED, DERIVED, ASSIMILATED, MODELED, FORECAST, or SIMULATED. Correlation edges never imply causation.

The uploaded fiber-optic/network image is a visual reference only: luminous nodes and strands inspire the relationship/network overlay; it is not treated as scientific data.
